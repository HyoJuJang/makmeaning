## 2026-09-22 선택 상품 추천과 화면 간소화

사용자 요청에 따라 구매·장바구니 상품을 클릭하면 그 상품 하나만 기준으로 추천하도록 변경했다. 이전에는 선택 상품을 기준 목록에 추가하면서 전체 이력도 함께 사용했다. 다른 구매·담기 상품은 중복 제외에만 남겼다. 방 화면은 홈 사용자를 사용하며 검토 화면의 저장 userid로 선택 상품을 무시하지 않는다.

선택 상품의 추천 후보는 카테고리 연결 규칙 또는 같은 분류 조건을 만족해야 한다. 다른 사용자와 행동이 겹친다는 이유만으로 무관한 분류를 추천하지 않는다. 후보가 부족할 때는 해당 상품의 카테고리 연결로만 보충하고, 전체 인기·기본 상품으로 채우지 않는다. 선택 상품이 인덱스에 없거나 관계가 없으면 빈 결과와 안내를 표시한다.

- 식품·뷰티의 별도 둘러보기 목록·정렬 UI 제거. 구매·장바구니 컬렉션·상세·찜·수량 관리는 유지.
- 모든 추천 화면에서 본/백업·나란히 비교·적용 버튼 제거. `/recommendations`는 단일 사용자 추천 검토 화면으로 변경.
