# 상품 이미지 표시 정정

사용자 요청: feat/game-asset-mapping의 핵심은 실사 상품 사진을 캐릭터와 공간 무드에 맞춘 상품 에셋으로 대체하는 것이다. 공간 안에서만 표시하고 목록에는 실사를 유지하던 이전 병합 결정을 정정한다.

- 준비된 동일 상품 ID·카테고리의 에셋을 구매 목록, 전체보기, 상품 상세, 찜/장바구니, 추천 카드에 공통 적용한다.
- 에셋의 검수 frame을 사용하고 비율을 유지한다. 상품명·가격·구매 ID·추천 순서는 변경하지 않는다.
- 미매핑·불러오기 실패 상품은 '공간 이미지 준비 중'으로 표시하며 실제 사진이나 임의의 다른 상품 그림으로 대체하지 않는다.
- 기존 가상 예시 상품은 기존 일러스트를 유지한다. 에셋 이미지는 실제 옵션·외형·가상 피팅을 보장하지 않는다.
- main 홈 이동/캐릭터/물리 구조는 수정하지 않는다. 기존 3112는 이전 빌드이므로 최종 검증 링크를 구분한다.
