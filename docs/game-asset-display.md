# 실제 공간에서 게임 에셋 표시

`/api/demo/home`은 기존 상품 DB와 구매 내역을 그대로 사용하면서, 각 실제 `prd_id`에 연결된 `ready` 에셋 하나의 메타데이터만 `gameAsset`으로 추가한다. 미연결·미검수·미생성 상품과 다른 도메인의 ID에는 `null`을 반환한다. 전체 상품 매핑 파일은 서버에만 남는다.

메인 미니룸의 옷장·냉장고·영양제 선반·생활·화장대 오브젝트와 상품 목록은 이 메타데이터가 있을 때 PNG를 표시한다. 위치·클릭 영역·옷장 흔들림·문 동작·식품 소진·조명 상태·구매 및 장바구니 ID는 기존 동작을 유지한다. 매핑이 없으면 기존 예시 그림을 표시하며 연결 완료로 취급하지 않는다.

패션·리빙 구매 상품 레일과 리빙의 기존 생활용품 그림, 식품·뷰티 상품 목록에도 같은 매핑을 사용한다. React 화면은 `GameItemSprite`, 기존 JavaScript 미니룸은 같은 프레임 방식의 `gameItemArt`를 사용하며 원본 PNG를 변경하지 않는다. 실제 상품사진은 변경하지 않는다. 패션·리빙의 가상 추천 상품 ID에 실제 상품 에셋을 임의로 연결하지 않는다.

에셋 추가 후 기존 `assets:build` / 빌드 준비 과정을 실행하고 페이지를 새로고침하면 새로 연결된 상품이 반영된다. 메인 JavaScript 모듈을 수정한 경우에도 준비 단계가 `public/prototype`에 복사한다.
