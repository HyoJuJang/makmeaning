# G:Scene — 52g 발표 자료

`GScene_Final_52g.pptx`: 편집 가능한 5장 PowerPoint.

`GScene_Final_52g.pdf`: 같은 5장 렌더를 담은 PDF 미리보기.

## 구성

1. GS SHOP의 상품을 자신의 생활에 연결하기 어려운 고객 문제 가설
2. 이미 가진 물건에서 다음 쇼핑을 시작하는 질문 전환
3. 내가 산 물건과 살아가는 G:Scene의 실제 방
4. 옷장 열림, 보유 옷의 명시 적용, 같은 방 복귀의 실제 연속 화면
5. 생활을 쇼핑의 출발점으로 삼는 제품 의미와 Agent 팀의 실행 방식

본문은 IBM Plex Sans KR을 사용한다. 원본 screenshot과 기획/구현 근거는 각 슬라이드의 발표자 노트에 있다. 가상 고객의 보유 상태, 일반화된 공간 그림, 아직 검증하지 않은 고객 효과를 구분한다. 그림은 상품의 정확한 외형이나 가상 피팅을 뜻하지 않는다.
