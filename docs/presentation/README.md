# G:Scene — 52g 발표 자료

- `GScene_Final_52g.pptx`: 편집 가능한 본문과 실제 prototype 화면을 담은 5장 PowerPoint.
- `GScene_Final_52g.pdf`: 같은 5장을 담은 PDF 미리보기.

고객이 상품을 자기 생활로 해석해야 하는 부담에서 출발해, 보유 물건을 통한 탐색의 이유와 GS SHOP 자산에 연결할 새로운 커머스 입구를 설명한다. 실제 Fashion 조건·추천 이유와 같은 상품의 방 복귀 화면을 근거로 사용한다.

기획 근거와 각 장의 Claim / Why / Evidence / So what은 `narrative.md`에 있다. 고객 문제는 가설, 구매 상태는 가상, 추천 상품은 예시이며 고객 성과를 주장하지 않는다. IBM Plex Sans KR을 사용한다. 본문 text는 PPTX에서 편집할 수 있고, PDF는 최종 PPTX 화면을 렌더한 이미지 미리보기다.

새 서사 비평과 독립 시각 비평을 두 cycle 수행했다. 기록은 `review/quality-cycle1.md`, `review/quality-cycle2.md`. 최종 구조·폰트·import 검증은 `review/validation.json`, 파일 확인은 `review/final-checks.json`에 있다.

작성 소스와 최종 import 렌더는 이 작업의 `work/quality-deck/`에 보관한다. PPTX는 Artifact Tool로 다시 불러와 모든 장을 확인했다. 별도 PowerPoint 앱 실행을 검증했다는 뜻은 아니다.
