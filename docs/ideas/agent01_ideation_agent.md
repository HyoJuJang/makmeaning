# Hackathon Ideation Agent

목표는 그럴듯한 기획서를 빨리 만드는 것이 아니라,
GS SHOP의 실제 고객 문제에서 출발해
“처음 들으면 조금 의외인데, 생각해보면 정확하다”는 아이디어를 찾는 것이다.

기존 `ideas` 문서는 선행 가설일 뿐 정답이 아니다.
필요하면 버리거나 완전히 다른 방향으로 가도 된다.

## 기본 원칙

### 1. 문제보다 해결책을 먼저 만들지 않는다

“AI 추천”, “개인화 피드”, “2030 UI”처럼
솔루션을 먼저 정한 뒤 문제를 끼워 맞추지 않는다.

실제 GS SHOP 경험을 보고 다음 순간을 찾는다.

* 고객이 직접 판단해야 하는 순간
* 귀찮지만 참고 하는 일
* 무엇을 원하는지는 알지만 무엇을 사야 할지 모르는 순간
* 사고 싶지만 확신이 없어서 멈추는 순간
* 다른 앱, 검색, 친구에게 도움을 요청할 것 같은 순간
* GS SHOP 밖에서 해결하고 있는 쇼핑 관련 행동

---

### 2. 표면 문제에서 한 번 더 내려간다

예:

검색이 어렵다
→ 원하는 검색어를 모르겠다
→ 사실 고객은 “상품”이 아니라 자신의 상황을 해결하고 싶다.

상품 비교가 어렵다
→ 정보가 많다
→ 사실 고객은 잘못 고르는 책임을 지고 싶지 않다.

최소 한 번은
“왜 이게 고객에게 문제인가?”
를 더 묻는다.

---

### 3. 너무 빨리 3개로 정리하지 않는다

먼저 서로 다른 문제 가설을 충분히 만든다.

그 후에만 후보를 줄인다.

비슷한 문제를 표현만 바꿔 여러 개로 만들지 않는다.

---

### 4. 뇌절은 하되 gimmick은 피한다

아이디어를 만들 때 일부러 기존 쇼핑 문법을 깨본다.

예:

* 고객이 상품을 찾지 않아도 된다면?
* Agent가 고객 대신 조사하고 판단한다면?
* 검색창 자체가 없다면?
* 쇼핑이 혼자 하는 행동이 아니라면?
* 구매 전이 아니라 구매 후까지 Agent가 책임진다면?
* 가격이나 상품이 아니라 “결정” 자체를 서비스한다면?
* GS가 가진 방송, 리뷰, 상품, 추천 데이터를 전혀 다른 방식으로 사용한다면?

단, 재미있기만 하고 실제 고객 문제를 해결하지 않는 아이디어는 버린다.

---

# 진행 순서

## STEP 1 — Observe

GS SHOP 모바일을 실제로 둘러본다.

홈만 보지 말고 가능한 범위에서

홈 → 탐색/카테고리 → 검색 → 상품상세 → 구매 고민

흐름을 본다.

관찰과 해석을 구분한다.

예:

관찰:
상품 상세에 정보와 리뷰가 많다.

해석:
고객은 정보를 얻지 못해서가 아니라
정보를 판단으로 바꾸는 데 에너지를 쓰고 있을 수 있다.

최소 8개의 관찰을 만든다.

---

## STEP 2 — Find the real problem

관찰에서 서로 다른 고객 문제 가설을 8~12개 만든다.

각 문제에는 다음을 짧게 붙인다.

* 누가
* 언제
* 무엇 때문에 막히는지
* 그 아래 숨어 있는 진짜 tension

그리고 그중 가장 강한 문제 4개를 남긴다.

선정 기준:

* 실제 행동에서 발생할 것 같은가
* 고객이 시간/노력/불확실성을 실제로 부담하는가
* 단순 UI 개선보다 더 깊은가
* GS SHOP이 풀 이유가 있는가

---

## STEP 3 — Go weird

남은 문제 4개 각각에 대해 해결 방향을 최소 4개씩 만든다.

처음에는 현실성을 조금 내려놓는다.

각 문제에서 최소 한 번은 다음 중 하나를 사용한다.

* Remove: 쇼핑 과정 하나를 없앤다.
* Invert: 기존 흐름을 반대로 만든다.
* Agent: AI가 고객 대신 행동한다.
* Social: 다른 사람이 경험에 들어온다.
* Zero UI: 화면을 최소화한다.
* Autopilot: 고객이 선택하지 않아도 된다.

총 16개 이상을 만든 뒤,

“웃기기만 한 아이디어”
“기존 쇼핑몰에 AI만 붙인 아이디어”
“기존 GS SHOP 기능과 거의 같은 아이디어”

를 제거한다.

---

## STEP 4 — Final 3

최종적으로 서로 다른 문제를 해결하는 아이디어 3개만 남긴다.

각 후보는 다음 형식으로 짧게 정리한다.

### 고객 문제

한 문장.

### Insight

왜 기존 쇼핑 경험이 이걸 잘 해결하지 못하는지.

### Big Idea

제품을 한 문장으로 설명.

### Magic Moment

사용자가 처음 “오?”라고 느끼는 순간.

### Agent

AI Agent가 실제로 무엇을 대신 수행하는지.

### Why GS

GS SHOP의 어떤 자산 때문에 가능한지.

### Demo

3분 안에 보여줄 핵심 장면.

마지막에만 `criterion`을 읽고
문제 정의가 억지거나 해커톤으로 구현하기 어려운 후보를 걸러낸다.
